# records — 記録の保管場所

記録アプリ（`../tracker/index.html`）から書き出したデータを置く場所です。

## 原本はGoogleドライブ

スマートウォッチの `.fit` ファイルは、**Googleドライブの「ランニングログ」フォルダ**に
保存しています。これが記録の原本です。このリポジトリには入れません
（走行位置を含むため、外部に出さない方針）。

```
Googleドライブ／ランニングログ／Zepp20260912165147.fit   ← 原本
        ↓ ドロップ
tracker/index.html                                       ← 集計・警告
        ↓ 書き出し
records/2026-09.csv                                      ← 手元の控え
```

取り込み方は [../docs/12-records.md](../docs/12-records.md) の
「スマートウォッチのログ（.fit）で管理する」を参照してください。

## ファイルの置き方

| ファイル名 | 内容 |
|---|---|
| `template.csv` | 手書きで記録する場合のテンプレート |
| `2026-09.csv` 〜 `2027-02.csv` | 月ごとの練習記録（CSVボタンから書き出し） |
| `backup-2026-12.json` | バックアップ（**Gitには入りません**） |

`backup-*.json` はリポジトリのルートの `.gitignore` で除外されています。
記録には体重や体調のメモが含まれるため、**意図せず公開されないようにしています。**

## バックアップの手順

1. `../tracker/index.html` を開く
2. 右上の「バックアップ」を押す
3. テキストをコピーし、`records/backup-YYYY-MM.json` として保存する

**月に1回を目安に。** ブラウザのデータを消すと記録は失われます。

## CSVで手書きする場合

`template.csv` をコピーして使ってください。列の意味は
[../docs/12-records.md](../docs/12-records.md) を参照。

時間は `h:mm:ss`、ペースは `m:ss`、痛みは `0`（なし）／`1`（違和感）／`2`（痛みあり）。
