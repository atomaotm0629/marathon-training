# 09 食事・体重・補給

---

## 日常の食事

特別な食事法は要りません。**3つだけ守ります。**

1. **炭水化物を減らさない。** 走るためのエネルギーです。
   減量目的で糖質を削ると、練習の質が落ちて故障します。
2. **たんぱく質を毎食とる。** 体重1 kgあたり1.2〜1.6 g/日
   （体重70 kgなら85〜110 g）。回復と筋の修復に必要。
3. **走った直後30〜60分に、炭水化物＋たんぱく質。**
   おにぎり＋牛乳、バナナ＋ヨーグルトで十分です。

### 不足しやすいもの

| 栄養素 | 不足の症状 | 摂り方 |
|---|---|---|
| 鉄 | 慢性的な疲労感、ペースが上がらない | 赤身肉、レバー、あさり。走行量が増える12〜1月は特に注意 |
| カルシウム・ビタミンD | 疲労骨折のリスク | 乳製品、小魚、日光 |
| 水分 | 冬は喉が渇かないので不足しやすい | 走る前後に意識的に |

## 体重

体重が1 kg減ると、フルマラソンのタイムは **おおよそ2〜3分** 速くなります。
ただし **筋肉が落ちれば逆効果** です。

| ルール | 内容 |
|---|---|
| 減量ペース | **月1 kgまで。** それ以上は筋肉が落ちる |
| 減量してよい時期 | 準備期〜第2期（9〜12月）まで |
| 減量してはいけない時期 | **第3期以降（12月中旬〜）。** 練習量が最大の時期に食事を削ると故障します |
| 調整期 | 減量しない。**むしろ炭水化物を増やす** |

記録アプリで体重を毎朝記録できます（任意）。
**日々の増減ではなく、1週間の平均値の推移を見てください。**

## 走る前の食事

| タイミング | 内容 |
|---|---|
| 3時間前 | 通常の食事（消化のよいもの。脂質・食物繊維は控えめ） |
| 1〜2時間前 | おにぎり1個、バナナ、カステラなど |
| 30分前 | 何も食べない方がよい（走り出しに胃が重くなる） |
| 直前 | 水を200 ml程度 |

**朝いちで走るときは、無理に食べなくても60分までなら問題ありません。**
90分を超えるロング走なら、必ず何か入れてから出ます。

---

## ロング走中の補給（練習から始める）

**90分を超える練習では、必ず補給の練習をします。**
本番で初めてジェルを飲むと、高確率で胃をやられます。

| 項目 | 目安 |
|---|---|
| 開始 | 走り始めて **45〜60分** の時点で1個目 |
| 間隔 | 以後 **30〜45分ごと** |
| 量 | ジェル1個＝約100〜120 kcal（糖質20〜30 g） |
| 水 | ジェルは必ず水と一緒に。水なしだと吸収が遅く、胃に残る |

### 何を使うか

- 味と粘度は製品差が大きい。**3種類くらい試して、合うものを見つける**
- 練習で合わなかったものは本番に持ち込まない
- カフェイン入りは終盤（30 km以降）に1個だけ、が扱いやすい

## レース前3日間（カーボローディング）

激しい方法は不要です。**「走る量を減らしながら、炭水化物の比率を上げる」** だけ。

| 日 | 内容 |
|---|---|
| 木（2/18） | 通常の食事。炭水化物をやや多めに |
| 金（2/19） | 炭水化物中心。脂質を減らす。**食物繊維を控える**（当日の腹痛対策） |
| 土（2/20） | 炭水化物中心。**夕食は早めに、食べ慣れたものを**。生もの・辛いもの・新しい店は避ける |
| 日（2/21）朝 | **スタート3時間前** に食べ慣れたもの。餅・おにぎり・カステラ・バナナ |

**水分**：前日から意識的に。ただし飲みすぎも危険（低ナトリウム血症）。
**アルコールは前日・前々日は避ける。** 脱水と睡眠の質の低下を招きます。

## レース当日の補給計画

### 給水

**全ての給水所で取る。** 喉が渇いてからでは遅い。
2月の京都は乾燥していて、喉の渇きを感じにくいので特に意識します。

| 項目 | 内容 |
|---|---|
| 量 | 1回100〜200 ml（紙コップを軽くつまんで飲む） |
| スポーツドリンクと水 | 前半はスポーツドリンク中心、後半は交互に |
| 取り方 | 立ち止まらず、歩く程度に減速して取る。**取ったら後続の邪魔にならない位置で飲む** |

## やってはいけないこと

- **本番で初めて口にする**（ジェル、スポーツドリンク、サプリ）
- **前日に食べ慣れないものを食べる**（京都に前泊するなら特に。名物は完走後に）
- **水の飲みすぎ**（体重が増えるほど飲むと低ナトリウム血症。手がむくむ、頭痛は危険信号）
- **レース直前の減量**（調整期の減量は、走力をそのまま削ります）
- **カフェインの初挑戦**（普段飲まない人が本番で摂ると胃腸が乱れる）
