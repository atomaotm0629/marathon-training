# 03 トレーニングの原則と週の組み立て方

細かいメニューより、この5つを守る方が結果に効きます。

---

## 原則1：ゆっくり走る日を、圧倒的に多くする（80/20）

市民ランナーが最も陥りやすい失敗は **「全部の練習が中途半端に速い」** こと。
きつくもないが楽でもない、というペースで毎回走ると、
疲労だけが溜まって走力は伸びません。

| 強度 | 割合 | 体感 |
|---|---|---|
| 楽（E＝イージー） | **80%** | 会話が続く。鼻歌が歌える |
| きつい（T・I） | 20% | 会話が途切れる／できない |

**ジョグは「遅すぎるかも」と思うくらいで正しい。**
遅く走ることで、毛細血管・ミトコンドリア・腱の強さといった、
マラソンに必要な土台が作られます。速く走ってもこれは手に入りません。

---

## 原則1.5：伸ばす順番は「時間 → 頻度 → 強度」

トレーニングで増やせるものは3つしかなく、**増やす順番が決まっています。**

| 順 | 何を | この計画では |
|---|---|---|
| **1** | **時間**（1回の長さ） | 準備期〜土台期（9〜11月中旬）はここだけ |
| **2** | **頻度**（週の回数） | 週3回を固める |
| **3** | **強度**（速さ） | 走力期（W5・11/16〜）から、**週1本だけ** |

**順番を飛ばして強度から入ると、ほぼ確実に故障します。**
逆に言えば、最初の2か月は「速く走る」ことを一切考えなくていい、ということです。

### なぜ遅く走るのか — 因果の向きが逆

「遅く走る」のは手加減ではありません。**量を積むための手段**です。

```
遅く走る → 疲れが残らない → 量が積める → 持久力がつく
                                    ↓
                       同じ心拍のまま、勝手に速くなる
```

**速さは「狙って上げるもの」ではなく「量を積んだ結果ついてくるもの」** です。
速く走ると1回は満足できますが、疲労が残って次が走れず、量が積めません。
結果として、遅く走った人の方が速くなります。

### 「距離」ではなく「時間」で測ってもいい

ペースを落とすと、同じ30分でも走る距離は減ります。
距離だけを見ていると「落ちた」と錯覚して、また速く走ってしまう——
これが最もよくある失敗の入口です。

- **体にかかる負荷は、距離よりも時間に比例します**（特に走り始めの時期）
- 「5 km走る」ではなく **「35分走る」** と考えると、ペースを落とすことに抵抗がなくなります
- 記録アプリの「今週のメニュー」には距離と一緒に **目安時間** も出ます。
  時計だけ見て走って構いません

### ポイント練習（速い練習）の位置づけ

この計画で速く走るのは、走力期（W5・11/16〜）からの **週1本だけ** です。
全体の1割以下しかありません。

- **「速く走る練習」ではなく「同じ楽さで走れる速度域を広げる練習」** です
- **プランA（完走狙い）なら、これを全部ジョグに置き換えても完走できます。**
  優先順位は常に **距離 ＞ 強度**
- 時間が取れない週は、真っ先にポイント練習を削ってください（原則4）

---

## 原則2：距離は週10%までしか増やさない

先週20 kmなら、今週は22 kmまで。これを超えると故障率が跳ね上がります。
**そして4週に1度は「回復週」として2〜3割落とす。**

```
第1週 22 km → 第2週 24 km → 第3週 26 km → 第4週 18 km（回復）
                                            ↑ ここで体が作り替えられる
```

走力が伸びるのは走っている最中ではなく、**休んでいる間** です。
回復週を飛ばすと、伸びないまま疲労だけが積み上がります。

記録アプリは、前週比が+10%を超えると警告を出します。

---

## 原則3：週に最低2日は完全休養

40代の体は、20代と同じ回復速度では動きません。
**「毎日走る」は、この計画では一度も出てきません。**

- プランA：週3回走る／週4日休む
- プランB：週4回走る／週3日休む
- プランC：週5回走る／週2日休む

休養日に罪悪感を持つ必要はありません。休養日はトレーニングの一部です。

---

## 原則4：ロング走が最重要。これだけは削らない

忙しくて練習が削れるとき、**最後まで残すのはロング走** です。

フルマラソンで起きる問題（脚が売り切れる、エネルギーが尽きる、
胃が受け付けなくなる、フォームが崩れる）は、
**2時間を超えてからしか現れません。** 短い練習を何本積んでも予行演習になりません。

優先順位：

```
1. 日曜のロング走       ← 何があっても守る
2. 週の合計距離         ← 本数を減らしてでも距離は確保
3. ポイント練習（T走・M走） ← 忙しい週は1本に減らしてよい
4. つなぎのジョグ       ← 最初に削る
```

---

## 原則5：痛みが出たら、その日のうちに止める

「様子を見ながら走る」で治った故障はほとんどありません。
判断基準は [08-injury.md](08-injury.md) にまとめてあります。

**3日休んで治る故障を、走り続けて3週間にする。** これが最大の損失です。
23週の計画において、3日の休養は1.8%、3週間の離脱は13%です。

## 週の組み立てテンプレート

> 下の表は日曜にロング走を置く場合です。**土曜でも構いません**（その場合は
> 曜日を1日ずつ前にずらす）。記録アプリの「ロング走の曜日」で切り替えると、
> 「今週のメニュー」がその形で組み直されます。
> 組み立ての考え方は [05-plan.md の「1週間の組み立て方」](05-plan.md) に。

### プランA（週3回）

| 曜日 | 内容 |
|---|---|
| 月 | 休養 |
| 火 | ジョグ 30〜40分＋補強10分 |
| 水 | 休養（または散歩・ストレッチ） |
| 木 | ジョグ 40分（うち後半は少し速く） |
| 金 | 休養 |
| 土 | 休養（または補強10分） |
| **日** | **ロング走** |

### プランB（週4回）

| 曜日 | 内容 |
|---|---|
| 月 | 休養 |
| 火 | ジョグ 40〜50分＋流し 4本 |
| 水 | 休養／補強10分 |
| 木 | **ポイント練習**（閾値走 or マラソンペース走） |
| 金 | 休養 |
| 土 | ジョグ 30〜40分（回復走） |
| **日** | **ロング走** |

### プランC（週5回）

| 曜日 | 内容 |
|---|---|
| 月 | 休養 |
| 火 | ジョグ 50〜60分＋流し 4本 |
| 水 | **ポイント練習**（閾値走・インターバル） |
| 木 | ジョグ 40分（回復走） |
| 金 | 休養／補強 |
| 土 | ジョグ 40〜50分 |
| **日** | **ロング走**（後半にマラソンペースを入れる） |

## 生活に組み込むための現実的な工夫

トレーニングが続かない理由は、たいてい意志ではなく **段取り** です。

| 工夫 | 内容 |
|---|---|
| 前夜に用意する | ウェア・シューズ・時計を玄関に出しておく。朝の判断コストをゼロにする |
| 走る時間を固定する | 「火・木の夜」「日曜の朝」と決める。毎回考えると決断疲れで続かない |
| 通勤を使う | 片道だけ走る／一駅手前で降りて歩く。ゼロの日を作らない |
| 繁忙期の代替 | 走れない日は「階段を使う」「10分の補強」に置き換え、記録には残す |
| 雨の日 | 無理に走らない。休養日と入れ替える。週の合計で帳尻を合わせる |

### 仕事の繁忙期への対応

| 時期 | 対応 |
|---|---|
| 11〜12月（年末の繁忙期） | ポイント練習を週1本に減らす。ロング走は死守 |
| 1月（月末期限の業務） | 同上。土日のどちらかでロング走を確保 |
| 2月（繁忙期の本番） | 調整期なので量は自然に減る。むしろ好都合 |
| 走れない週があった | 焦って取り返さない。翌週は前週比+10%以内に戻すだけ |

**1週間まるごと走れなくても、計画は壊れません。**
壊れるのは、取り返そうとして2週分を1週で走ったときです。
