# 10 シューズとギア

**お金をかける優先順位は、シューズ → 靴下 → その他** です。

---

## シューズ

### 1足目：デイリートレーナー（最優先・準備期のうちに）

練習の8割を走る靴。ここを外すと故障します。

| 項目 | 選び方 |
|---|---|
| 種類 | **クッション性のある厚めのトレーニングシューズ** |
| サイズ | 実寸＋1.0〜1.5 cm。夕方（足がむくんだ状態）に試す |
| 買い方 | **必ず店舗で試し履きする。** 可能なら専門店で足を計測してもらう |
| 避けるもの | 薄底のレーシングシューズ、ファッション系スニーカー、5年前の靴 |

**カーボンプレートの入った厚底レーシングシューズを最初の1足にしない。**
脚ができていない段階では、ふくらはぎとアキレス腱への負担が大きすぎます。

### 2足目：ローテーション用（W1〜W5あたりで）

同じ靴を毎回履くと、同じ場所に同じ負担がかかります。
2足を交互に履くと故障率が下がり、靴の寿命も延びます。
1足目と少しタイプの違うもの（やや軽い、反発のあるもの）を選ぶと使い分けができます。

### レース用（買うなら12月まで）

| 目標 | 選択 |
|---|---|
| 完走（プランA） | **買わない。履き慣れたデイリートレーナーで走る方が安全** |
| サブ5（プランB） | 買わなくてよい。軽量トレーナーがあれば十分 |
| サブ4（プランC） | 軽量シューズまたは厚底レーシング。**12月までに買い、W15の予行ロング走を含め100 km以上履いてから本番へ** |

**本番で初めて履く靴は、絶対に避けてください。**

### 足を測ってもらう（最優先。無料で、一生使える）

スポーツ店の多くに **3Dスキャンの計測機** があります。2分で終わり、たいてい無料です。
出てくるのは4つ。

| | 何が分かるか |
|---|---|
| **足長** | 推奨サイズ（足長＋1.0〜1.5 cmが目安） |
| **足幅（ワイズ）** | D / 2E / 4E のどれを買うか |
| **アーチの高さ** | 内側に倒れやすいかどうか |
| 甲の高さ・かかとの幅 | 紐の締め方の指針 |

**この数字が分かると、どの店でも「◯◯ cmの◯Eで、クッションのある練習用を」の
一言で済みます。** ネットで買うときの失敗も減ります。

#### かかとが抜ける／甲が痛いとき：ヒールロック

**甲が低い・かかとが狭い**足型だと、紐を締めると甲が痛み、緩めるとかかとが浮く、
という板挟みになります。サイズの問題ではなく、**紐の通し方で解決します。**

> 靴紐の穴は、いちばん上に **ひとつ余っている** はずです（少し離れた位置の穴）。
>
> 1. 左右それぞれ、その**余った穴に同じ側から紐を通し、小さな輪を作る**
> 2. **反対側の紐を、その輪に通す**
> 3. そのまま普通に結ぶ
>
> かかとだけが引き寄せられ、甲は締めずに済みます。

ロング走で **足が前に滑って爪が黒くなる** のも、これで防げます。
**長い距離を走る前に、一度試しておいてください。**

#### アーチが低い（扁平足寄り）と言われたら

内側に倒れやすい傾向はありますが、**痛みが出ていないなら何もしなくて構いません。**
出ていない問題を先回りで直す必要はありません。

**膝の内側・脛の内側**が痛み出したら、そのときにサポート系
（ニューバランス 860、アシックス GT-2000／KAYANO など）を検討します。

### 交換時期

- **500〜700 km** が目安。記録アプリでシューズ名を記録すると累積距離が出ます
- ソールの模様が消えた、クッションが硬く感じる、膝や足裏が痛み出した → 交換
- **レース前1か月で新品に替えない。** 替えるなら12月まで

## 靴下

**マメの9割は靴下で防げます。**

- ランニング専用の靴下（厚手・縫い目が少ない・ズレない）
- **綿はだめ。** 汗を吸って重くなり、摩擦でマメになる
- 5本指タイプが合う人も多い。ロング走で試して決める
- 本番用の靴下は、W15の予行ロング走で必ず使ってみる

## 雨の日

### レインウェアは着ない

防水ジャケットは汗を外へ逃がせません。**20分で内側からびしょ濡れ**になり、
濡れることは同じで、重くて暑いぶん悪くなります。
高価な防水透湿素材でも、走るときの発汗量には追いつきません。

**雨の日の問題は「濡れること」ではなく「濡れた体が風で冷えること」です。**
だから防水ではなく、**風を止めるもの**を着ます。

### 気温で決める。雨かどうかで決めない

| 気温 | 装備 |
|---|---|
| **15℃以上** | **そのまま濡れる。** Tシャツと短パンで構わない |
| 10〜15℃ | 長袖（化繊）＋薄いウインドブレーカー。**防水でなくてよい** |
| **5〜10℃**（2月の京都） | 長袖＋ウインドブレーカー＋**手袋**＋**つば付き帽子** |
| 5℃未満の雨 | **最も危険。** 無理に走らない |

**冷たい雨は雪より危険です。** 濡れた肌＋風は、乾いた寒さより速く体温を奪います。

### 効くのは安いもの

| | なぜ |
|---|---|
| **つば付きの帽子** | **いちばん効く。** 目に雨が入らないだけで別物になる |
| **手袋** | 手は最初に冷えて最後まで戻らない。軍手でも可 |
| **ワセリン**（乳首・股・脇） | **濡れた生地は必ず擦れる。** 雨の日に股ずれは起きる |
| 反射材 | 雨＋夕方は、運転手から本当に見えない |

**綿は着ない。** 水を吸って保温力がゼロになり、擦れます。化繊だけ。

### 濡れた靴の乾かし方

**24〜48時間乾きません。**

- **中敷きを抜き、新聞紙を詰めて、室温で。** 新聞紙は2〜3回替える
- **ドライヤー・暖房・乾燥機は厳禁。** 熱でミッドソールの接着と発泡が壊れます。
  **一晩で1足を駄目にできます**

これが **2足持つ理由のひとつ** です。1足しかないと、雨の翌日に履く靴がありません。

### 路面

- **白線・マンホール・横断歩道の塗装・落ち葉はよく滑る**
- 河川敷はぬかるみ、**増水すると閉鎖される**
- **ペースは落ちる。それでよい。** 時計ではなく心拍と体感で走る

雨の日は **心拍計がさらに当てになりません**（冷えて皮膚の血流が減るため。
[光学式心拍計の限界](#光学式心拍計の限界手首の時計で測るということ)）。

### 中止する条件

| | |
|---|---|
| **雷** | 迷わず中止 |
| 強風・台風 | 中止 |
| 河川敷の増水 | 中止 |
| 路面凍結 | 中止 |

**雨だけなら中止の理由になりません。** ただし原則は
「無理に走らない。休養日と入れ替える。週の合計で帳尻を合わせる」
（[03-principles.md](03-principles.md)）。日曜のロング走が雨なら、
土曜か月曜にずらす方が筋が通っています。

> **ただしW15（1/25週）の本番予行だけは、雨でも実施します。**
> 2月21日に雨が降る可能性は十分あり、そのとき初めて雨のマラソンを経験するのは
> 避けたい。予行の目的は、装備の問題を全部洗い出すことです。

## 2月21日・京都の服装

2月下旬の京都は **最低0〜3℃、スタート時5℃前後**。盆地で底冷えします。

### 走っているとき

**「走り出して5分で少し寒い」くらいが正解。** 走ると体感で10℃上がります。

| 部位 | 推奨 |
|---|---|
| 上 | 長袖インナー（化繊・吸汗速乾）＋半袖Tシャツ。**綿は禁物** |
| 下 | ランニングタイツ または ハーフパンツ＋タイツ |
| 手 | **手袋は必須。** 安い軍手でも可（暑くなったら捨てられる） |
| 頭・耳 | ニット帽 または イヤーウォーマー。序盤は効果が大きい |
| 腕 | アームウォーマー（暑くなったら下ろせる＝**調整弁として非常に優秀**） |

### スタートまでの待機（ここが最も過酷）

整列から号砲まで20〜40分、屋外で立ち続けます。

| アイテム | 用途 |
|---|---|
| **使い捨てのポンチョ／大きめのゴミ袋** | 防風。スタート直前に脱いで捨てる。最も効果的で安い |
| 使い捨てカイロ | 腰と腹に |
| 捨ててよい上着 | 着古したウインドブレーカーなど |
| 予備の靴下 | 足先の冷え対策 |

**雨の予報なら、ポンチョは必携です。** 濡れて冷えるのが最も危険。

### フィニッシュ後

**汗が冷えて一気に体温が下がります。** 荷物に必ず入れておくもの：

- 乾いた着替え（上下）・タオル
- 防寒着（ダウンなど）
- 暖かい飲み物を買う小銭

## 光学式心拍計の限界（手首の時計で測るということ）

手首の時計は、**皮膚に光を当てて血流の脈動を読んでいます**（光学式／PPG）。
胸ベルトのように心臓の電気信号を直接拾っているわけではありません。

このため、**強度が上がるほど読みにくくなります。** 原因はひとつではありません。

| | |
|---|---|
| **皮膚の血流が減る**（主） | 強度が上がると血液は筋肉へ回され、手首の皮膚の血流は減る。**読む信号そのものが小さくなる** |
| **冷え**（主） | 冬の夜は手首が冷え、さらに血流が減る |
| 接地の衝撃 | 腕を振らなくても、1分間に180回の着地衝撃が体を伝って時計を揺らす |
| 前腕の力み | 腕を固定して走ると前腕に力が入り、時計の下の組織が圧迫される |
| 時計のゆるみ | ゆるいと滑って読めない |

**「腕を大きく振るから」ではありません。** 腕を振らない走り方でも同じように起きます。

### 実測で確認された挙動（Amazfit T-Rex 3）

本気で限界近くまで行った3回を並べると、はっきり出ます。

| いつ | 動き | ピッチ | 最高心拍 |
|---|---|---|---|
| 夏・標高2500 mの登山 | **歩き**（腕が静か） | 低い | **180** |
| 10 km走の終盤・失速中 | 走り | 約164 | **190** |
| **全力5 km** | 走り（速い） | **184** | **174** |

同じ日の裏づけもあります。アップ（歩き＋流し・ピッチ154）の最高が **178**、
その **76秒後** に始めた全力5 km（ピッチ184）の最高が **174**。
同じ手首で、1分半差です。

**最も速く・最も強度の高かった1本だけが、いちばん低い値で止まっています。**

ただし **断定はできません。** 失敗例は1本だけで、この3回は速度・ピッチ・気温が
すべて違うため、どれが効いたのかを切り分けられていません。
さらに、**単に出し切っていなかった**可能性も残ります。30分走で最大心拍に届くのは
最後の1〜2分だけで、それもゴールで倒れ込むくらい出し切った場合です。
この5 kmはネガティブスプリット（5'58"→5'49"）で終えており、余力が残っていた
かもしれません。

**そしてこの3つは、どう置いても1本が余ります。**

| | 最大190なら | 最大181なら |
|---|---|---|
| 9/12の190 | 100% | **105%（ありえない）** |
| 登山の180 | 95% | 99% |
| 全力5 kmの174 | **92%（出し切って届かない）** | 96% |

最大181とすれば登山も全力5 kmもきれいに説明がつき、合わないのは9/12だけ。
最大190とすれば9/12は説明がつくが、30分出し切って92%止まりだったことになる。
9/12の190には人工物の証拠が見つかっていない（1〜2秒で8拍以上飛んだ箇所ゼロ、
そのときのピッチは165なのでケイデンスロックでも倍音でもない）ので、捨てられない。

**決着していません。**

> 最大心拍は高度では上がりません（むしろわずかに下がります）。
> 標高2500 mで180が出たなら、平地の最大はそれ以上ということだけは言えます。

### どう付き合うか

| 強度 | 手首の時計 | 何で管理するか |
|---|---|---|
| E・ジョグ・ロング走 | **使える** | 心拍でよい |
| M・レースペース | たぶん使える | 心拍＋ペース |
| **T・I・タイムトライアル** | **当てにならない** | **ペースとRPEで管理する** |

幸い、**速い練習はもともとペースで管理するもの**なので実害は限定的です。
日常的に使うE上限も、センサーが信頼できる範囲に入っています。

**W5（11月中旬）から閾値走が始まります。** そこからは心拍の上限を見ずに、
**Tペースと RPE 7〜8** で管理してください（[04-paces.md](04-paces.md)）。

### 確かめ方（お金はかかりません）

強い走りをした**直後に、自分で脈を数えます。** 手首か首で **15秒数えて4倍**。

| 時計の表示に対して | 結論 |
|---|---|
| ほぼ一致 | 時計は正しい。**最大心拍の設定を下げる** |
| 手で数えた方が10拍以上高い | **時計が低く出ている。設定はそのまま** |
| 測れなかった／曖昧 | **低い方に倒す**（下の理由） |

#### 迷ったら低い方に倒す

最大心拍の設定を間違えたときの代償は、上下で釣り合っていません。

| 設定 | 実際がそれより低かった | 実際がそれより高かった |
|---|---|---|
| **高めに設定** | **速すぎる練習を続ける**（故障と疲労の蓄積） | 正しい |
| **低めに設定** | 正しい | 少し遅すぎる（損失は小さい） |

練習の8割はEゾーンで、**そこは遅すぎても失うものがほとんどありません。**
分からないときは低い方を採ります。

あわせて、**時計を手首の骨から指2〜3本ぶん上に、走る間だけきつめに締める**。
装着位置と締め具合だけで直ることがあります。

### 胸ベルト式を買うか

**急ぎません。** 必要になるのは閾値走が始まるW5以降で、そこもペース管理で代用できます。

| | 手首（光学式） | 胸ベルト（電気式） |
|---|---|---|
| 高強度での精度 | **低い** | 高い |
| 低強度での精度 | 十分 | 高い |
| 手軽さ | 着けっぱなしでよい | 走るたびに装着 |
| 安静時心拍・睡眠 | **測れる** | 測れない |

胸ベルトを買っても、**安静時心拍と睡眠の記録は時計側が担当**なので、
時計を外すことにはなりません。両方使う形になります。

## 揃える順番と時期

| 時期 | 買うもの |
|---|---|
| 準備期（9月） | デイリートレーナー、ランニング靴下、反射材、ワセリン |
| W1〜W5（10〜11月） | 2足目のシューズ、ジェル携帯ポーチ、冬用ウェア、（任意）胸ベルト式心拍計 |
| W9〜W13（12〜1月） | 本番用ウェア一式、（必要なら）レース用シューズ、ジェルの本命を決める |
| W15（1/25週） | **予行ロング走で本番の装備を全部使う** |
| レース週（2月） | 使い捨てポンチョ、カイロ、着替え |

**W15の予行ロング走までに、本番で使うものを全て揃えて試す。**
これが装備に関する唯一で最大のルールです。
