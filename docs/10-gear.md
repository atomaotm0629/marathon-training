# 10 シューズとギア

**お金をかける優先順位は、シューズ → 靴下 → その他** です。

---

## シューズ

### 1足目：デイリートレーナー（最優先・準備期のうちに）

練習の8割を走る靴。ここを外すと故障します。

| 項目 | 選び方 |
|---|---|
| 種類 | **クッション性のある厚めのトレーニングシューズ** |
| サイズ | 実寸＋1.0〜1.5 cm。夕方（足がむくんだ状態）に試す |
| 買い方 | **必ず店舗で試し履きする。** 可能なら専門店で足を計測してもらう |
| 避けるもの | 薄底のレーシングシューズ、ファッション系スニーカー、5年前の靴 |

**カーボンプレートの入った厚底レーシングシューズを最初の1足にしない。**
脚ができていない段階では、ふくらはぎとアキレス腱への負担が大きすぎます。

### 2足目：ローテーション用（W1〜W5あたりで）

同じ靴を毎回履くと、同じ場所に同じ負担がかかります。
2足を交互に履くと故障率が下がり、靴の寿命も延びます。
1足目と少しタイプの違うもの（やや軽い、反発のあるもの）を選ぶと使い分けができます。

### レース用（買うなら12月まで）

| 目標 | 選択 |
|---|---|
| 完走（プランA） | **買わない。履き慣れたデイリートレーナーで走る方が安全** |
| サブ5（プランB） | 買わなくてよい。軽量トレーナーがあれば十分 |
| サブ4（プランC） | 軽量シューズまたは厚底レーシング。**12月までに買い、W15の予行ロング走を含め100 km以上履いてから本番へ** |

**本番で初めて履く靴は、絶対に避けてください。**

### 交換時期

- **500〜700 km** が目安。記録アプリでシューズ名を記録すると累積距離が出ます
- ソールの模様が消えた、クッションが硬く感じる、膝や足裏が痛み出した → 交換
- **レース前1か月で新品に替えない。** 替えるなら12月まで

## 靴下

**マメの9割は靴下で防げます。**

- ランニング専用の靴下（厚手・縫い目が少ない・ズレない）
- **綿はだめ。** 汗を吸って重くなり、摩擦でマメになる
- 5本指タイプが合う人も多い。ロング走で試して決める
- 本番用の靴下は、W15の予行ロング走で必ず使ってみる

---

## 2月21日・京都の服装

2月下旬の京都は **最低0〜3℃、スタート時5℃前後**。盆地で底冷えします。

### 走っているとき

**「走り出して5分で少し寒い」くらいが正解。** 走ると体感で10℃上がります。

| 部位 | 推奨 |
|---|---|
| 上 | 長袖インナー（化繊・吸汗速乾）＋半袖Tシャツ。**綿は禁物** |
| 下 | ランニングタイツ または ハーフパンツ＋タイツ |
| 手 | **手袋は必須。** 安い軍手でも可（暑くなったら捨てられる） |
| 頭・耳 | ニット帽 または イヤーウォーマー。序盤は効果が大きい |
| 腕 | アームウォーマー（暑くなったら下ろせる＝**調整弁として非常に優秀**） |

### スタートまでの待機（ここが最も過酷）

整列から号砲まで20〜40分、屋外で立ち続けます。

| アイテム | 用途 |
|---|---|
| **使い捨てのポンチョ／大きめのゴミ袋** | 防風。スタート直前に脱いで捨てる。最も効果的で安い |
| 使い捨てカイロ | 腰と腹に |
| 捨ててよい上着 | 着古したウインドブレーカーなど |
| 予備の靴下 | 足先の冷え対策 |

**雨の予報なら、ポンチョは必携です。** 濡れて冷えるのが最も危険。

### フィニッシュ後

**汗が冷えて一気に体温が下がります。** 荷物に必ず入れておくもの：

- 乾いた着替え（上下）・タオル
- 防寒着（ダウンなど）
- 暖かい飲み物を買う小銭

## その他のギア

| アイテム | 要否 | 備考 |
|---|---|---|
| GPSウォッチ | **あると計画の精度が上がる** | スマホアプリでも可。ペース管理と記録に |
| ジェル携帯用ポーチ | ほぼ必須 | 4〜5個入るもの。**ロング走で揺れないか試す** |
| ワセリン | **必須** | 脇・股・乳首・足指に。擦れの防止 |
| 絆創膏／テーピング | 必須 | 乳首の擦れ防止（男性は特に） |
| 帽子・サングラス | 任意 | 2月なら優先度は低い |
| ゼッケンベルト | 任意 | ウェアに穴を開けたくない場合 |
| 反射材 | **夜に走るなら必須** | 冬は日没が早く、平日練習はほぼ夜 |
| ライト | 夜練習用 | 河川敷は暗い |

---

## 揃える順番と時期

| 時期 | 買うもの |
|---|---|
| 準備期（9月） | デイリートレーナー、ランニング靴下、反射材、ワセリン |
| W1〜W5（10〜11月） | 2足目のシューズ、ジェル携帯ポーチ、冬用ウェア |
| W9〜W13（12〜1月） | 本番用ウェア一式、（必要なら）レース用シューズ、ジェルの本命を決める |
| W15（1/25週） | **予行ロング走で本番の装備を全部使う** |
| レース週（2月） | 使い捨てポンチョ、カイロ、着替え |

**W15の予行ロング走までに、本番で使うものを全て揃えて試す。**
これが装備に関する唯一で最大のルールです。
