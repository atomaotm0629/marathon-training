# 08 故障の予防と、痛みが出たときの判断

**この計画が失敗する原因の第1位は、走力不足ではなく故障です。**

23週のうち3日休むのは 1.8%。3週間離脱するのは 13%。
**「早く休む」ことが、最も速く走るための手段です。**

---

## 痛みが出たときの判断フロー

```
痛みを感じた
   │
   ├─ 走っているうちに消える（ウォームアップで軽くなる）
   │     → その日は予定どおり。ただしペースは上げない。翌日も続くなら下へ
   │
   ├─ 走るほど強くなる／フォームが変わる
   │     → その場で中止。歩いて帰る
   │
   ├─ 翌朝、階段の上り下りで痛む
   │     → 3日休む。3日後に20分ジョグで確認
   │
   ├─ 安静にしていても痛む／腫れ・熱を持つ
   │     → 走らない。整形外科へ
   │
   └─ 一点を押すと鋭い痛み（特にすね・足の甲）
         → 疲労骨折の可能性。自己判断で走らない。整形外科へ
```

### 3日休んだあとの再開手順

| 日 | 内容 |
|---|---|
| 1日目 | 20分ジョグ（Eより遅く）。痛みが出たら中止してさらに3日休む |
| 2日目 | 休養 |
| 3日目 | 30分ジョグ |
| 4日目以降 | 痛みがなければ、**休む前の週間距離の7割から** 再開 |

**元の距離にいきなり戻さない。** 再発の典型パターンです。

## よくある故障と原因

| 故障 | 症状 | 主な原因 | 対処 |
|---|---|---|---|
| **ランナー膝**（腸脛靭帯炎） | 膝の**外側**が痛む。下りや階段で悪化 | 中殿筋の弱さ、急な距離増、シューズの摩耗 | 休養＋サイドレッグレイズ（[07](07-strength.md)）。腸脛靭帯のストレッチ |
| **膝蓋大腿痛** | 膝の**前・皿の周り**が痛む | 大腿四頭筋の使いすぎ、下り走りすぎ | 休養＋スクワット。下り坂を避ける |
| **シンスプリント** | すねの内側が広い範囲で痛む | 急な距離増、硬い路面、クッション不足 | 2週間は距離を半分に。カーフレイズ、路面を変える |
| **疲労骨折** | すね・足の甲の**一点**が鋭く痛む | シンスプリントを放置した結果 | **必ず受診。** 走ると悪化する |
| **アキレス腱炎** | かかと上部が痛む。朝の一歩目が痛い | 急なスピード練習、坂の走りすぎ | 休養＋カーフレイズ（下ろす動作をゆっくり） |
| **足底腱膜炎** | かかと〜土踏まずが痛む。**朝の一歩目が最も痛い** | 足裏の硬さ、シューズの摩耗、体重増 | 足裏をボールで転がす。ふくらはぎのストレッチ。長期化しやすい |
| **腸腰筋・股関節前の張り** | 脚の付け根が痛む | 座り仕事＋走り込み | 腸腰筋ストレッチ（[07](07-strength.md)） |

## 予防（これをやれば大半は起きない）

1. **週10%ルールを守る**（[03-principles.md](03-principles.md)）
2. **回復週を飛ばさない**（W4・W8・W11・W14）
3. **週2回・10分の補強**（[07-strength.md](07-strength.md)）
4. **シューズを500〜700 kmで交換する**（[10-gear.md](10-gear.md)）
5. **ジョグを速く走らない**
6. **同じコース・同じ路面ばかり走らない**（片側が傾いた道は特に注意）
7. **睡眠を削らない。** 繁忙期に走行距離を維持して睡眠を削るのは、最悪の選択

---

## 「休むべきか」に迷ったときの3つの質問

1. **今日走らないと、何が失われる？** → 1回のジョグ分。ほぼ何も失われません
2. **今日走って悪化したら、何が失われる？** → 2〜6週間と、レース
3. **明日も同じ痛みがあったら休む？** → イエスなら、今日休む方が早く治ります

---

## 体調不良のときの判断（ネックルール）

| 症状の位置 | 判断 |
|---|---|
| 首から**上**だけ（鼻水・喉の軽い違和感） | 軽いジョグなら可。強度は上げない |
| 首から**下**（咳・胸の症状・全身のだるさ・筋肉痛様の痛み） | **走らない** |
| 発熱 | **走らない。** 解熱後も2〜3日は休む |

**発熱時のランニングは心筋炎のリスクがあります。** ここは例外なく休んでください。

---

## 疲労のサイン（故障の手前で気づく）

記録アプリに毎日入れる数字で、次のパターンが出たら回復週を前倒しします。

| サイン | 意味 |
|---|---|
| 同じペースなのにRPEが2以上高い日が続く | 疲労蓄積 |
| 朝起きたときの心拍数が普段より5〜10拍高い | 回復していない |
| 寝つきが悪い・夜中に目が覚める | オーバートレーニング初期 |
| 食欲がない | 同上 |
| 脚の重さが3日以上抜けない | 同上 |
| 走りたくない気分が1週間続く | 体からの正しい信号 |

**該当したら、その週は距離を3割落とす。** 計画より体を優先します。

---

## 受診の目安

以下は自己判断せず、整形外科（できればスポーツ整形）へ。

- 一点を押すと鋭い痛みがある（疲労骨折の疑い）
- 腫れ・熱感・内出血がある
- 3日休んでも、20分ジョグで同じ痛みが出る
- 痛みで日常生活（階段・歩行）に支障がある

**受診するとき「京都マラソン（2027/2/21）に出たい」と伝えてください。**
完全に治すまで走らない方針か、調整しながら続ける方針かで、治療方針が変わります。
